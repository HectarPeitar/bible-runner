# Who translates, and what happens when a string is missing

Type: grilling
Status: open
Blocked by: 01, 02

## Question

Decide the translation policy: who produces the ~25 interface strings in four languages (the agent drafts, a native speaker friend corrects, or the agent alone), the shape of the string tables (one file per locale versus one file holding all locales), the fallback order when a key is missing, whether the locale can change mid-run, and whether aliases appear only in the player's own locale.

Note the Georgian font requirement and who verifies Georgian and Russian copy. Being honest that machine-translated book names are a correctness risk, not just a typo risk, is part of the answer.
