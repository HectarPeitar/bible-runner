# Local scoreboard: entries, names, and when it prompts

Type: grilling
Status: open
Blocked by:

## Question

All play is local — no server, no accounts. Pin the scoreboard:

- **What a score is.** Books passed? Penalty for a miss? Time? A section's run is a fixed length, so what actually varies between runs? A leaderboard is only meaningful once this is answered.
- **When it prompts for a name.** "Higher than the one before it" has two readings: higher than *your own previous run*, or high enough to enter the top-N board. Decide which, and say what happens on the very first run, when there is no previous score.
- **Board scope.** One board per section, one global board, or one per section *and* locale. Locale matters: a name typed in Georgian and one typed in Dutch should not silently share one list if that is confusing.
- **Entries.** How many, how ties rank, whether an entry can be deleted, and what happens when the board is full.
- **Name entry.** Length limit, characters allowed, and the remembered last name pre-filled from local storage — the pre-fill is the one piece of remembered identity in the game, so be explicit that it is stored locally and nothing more.
- **Where the board lives.** Result screen, mode picker, or its own screen.
