# Local scoreboard: entries, names, and when it prompts

Type: grilling
Status: open
Blocked by:

## Question

All play is local — no server, no accounts.

**Settled by the operator:** a **top-N** board — a run that lands in the top N prompts for a name and joins the board; one that does not, does not. Gaps cost score (miss penalty), so a clean run and a sloppy one are not worth the same.

Still to pin:

- **The score formula, and whether speed multiplies it.** Books passed minus penalties is the base; the open question is whether a fast run outscores a slow clean one. That single choice decides whether the board rewards mastery or merely certifies that a section was finished.
- **N, and ties.** How many entries the board holds, how equal scores rank, and what happens when a qualifying score arrives at a full board.
- **Boards per route.** A canon route is up to 66 books long; a section route is five. One shared board means canon scores always win and the section board is decoration. Decide whether each route gets its own board, whether the section route gets one board per section, and whether a canonical "start at X" run is comparable to a full Genesis→Revelation run.
- **Board scope.** One board per section, one global board, or one per section *and* locale. Locale matters: a name typed in Georgian and one typed in Dutch should not silently share one list if that is confusing.
- **The first run.** What happens before the board has N entries — does every run qualify until it is full?
- **Name entry.** Length limit, characters allowed, and the remembered last name pre-filled from local storage — the pre-fill is the one piece of remembered identity in the game, so be explicit that it is stored locally and nothing more.
- **Where the board lives.** Result screen, mode picker, or its own screen.
