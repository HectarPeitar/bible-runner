# Glossary

**Book** — one of the 66 texts of the canon, with a fixed position in the order and exactly one name per locale: the New World Translation's.

**Canon** — the closed, ordered list of books a player is being taught. This game teaches the New World Translation's canon: 66 books in Protestant order.

**Book Order** — the game's first mode: continuing the canon in the correct sequence.

**Route** — the kind of travel a Book Order run makes. A **section route** loops a course; a **canon route** travels the canon from a chosen starting section. The route is a setting of the mode, not a mode of the game.

**Course** — a contiguous grouping of sections that a section route loops, long enough to be worth drilling. There are five: Genesis–Song of Solomon (sections 1–3, 22 books), Isaiah–Malachi (4–5, 17), Romans–Jude (8–9, 21), Genesis–Malachi (1–5, 39), Matthew–Revelation (6–10, 27). Courses overlap by design and each is an independent loop. They are labelled by their first and last **Book**, never by an invented name: the NWT has no "Wisdom" or "Epistles", and a label the game made up would be vocabulary it then taught to people who are playing to learn the right vocabulary.

**Section** — one of the ten traditional groupings of the canon. The unit a canon route can *start* at, and the unit a course is built from. Playing a course is not the same as playing a section. Also labelled by book range (`Genesis–Deuteronomy`, `Joshua–Esther`) for the same reason.

**Start point** — the section a canon route begins at. Every section is a valid start point, whether or not it belongs to a course.

**Run** — one play of a mode, from start to result. A Book Order run travels one route.

**Row** — the three Gates that arrive together, one per Lane, exactly one carrying the next Book.

**Lane** — one of the three columns the Runner can occupy. A Row judges the Gate in the Runner's Lane.

**Gate** — an oncoming carrier of a Book's name, occupying one Lane. Exactly one Gate in a Row carries the next Book.

**Distractor** — a Gate carrying a Book that is not the next one. Plausible Distractors come from near the answer, not from anywhere in the canon.

**Runner** — the thing the player steers. It occupies one Lane at a time and moves one Lane per keypress.

**Stumble** — arriving at a Row in the wrong Lane. The Runner is pushed back along the road, the world slows for a beat, and the Gate holding the next Book is marked so the Runner can steer into it. The Row's points are lost; the Book still counts as reached.

**Marked gate** — the Gate in a Stumbled Row that carries the next Book, shown so the recovery is visible. Not the same as "the correct Gate", which every Row has whether or not anyone stumbles.

**Caught** — the run-ending state: a Row reaches the Runner while it is still in the wrong Lane.

**Review** — the list of Books a Run stumbled on, in canon order, shown when it ends.

**Speed** — how fast Rows arrive, and therefore the rate points are earned. It climbs as a Run goes, rises toward a ceiling rather than forever, and resets to its starting value on a Stumble.

**Start boost** — an elevated starting speed, earned by a clean route rather than granted by a menu.

**Mode** — a ruleset played over the shared content, with its own way of scoring and ending. Book Order is the first mode; the game is a container for modes.

**Locale** — the language and script a player plays in. Book names and interface text are always in the same locale.
