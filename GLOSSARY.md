# Glossary

**Book** — one of the 66 texts of the canon, with a fixed position in the order.

**Canon** — the closed, ordered list of books a player is being taught. This game teaches the New World Translation's canon: 66 books in Protestant order.

**Book Order** — the game's first mode: continuing the canon in the correct sequence.

**Route** — the kind of travel a Book Order run makes. A **section route** loops a course; a **canon route** travels the canon from a chosen starting section. The route is a setting of the mode, not a mode of the game.

**Course** — the named grouping of sections that a section route loops. Courses group sections so a loop is long enough to drill: `Law, History & Wisdom` (sections 1–3), `Major and Minor Prophets` (4–5), `Epistles` (8–9).

**Section** — one of the ten traditional groupings of the canon. The unit a canon route can *start* at, and the unit a course is built from. Playing a course is not the same as playing a section.

**Start point** — the section a canon route begins at. Every section is a valid start point, whether or not it belongs to a course.

**Run** — one play of a mode, from start to result. A Book Order run travels one route.

**Gate** — an oncoming obstacle carrying a book's name. Reaching the correct next book passes it; reaching any other costs a life.

**Distractor** — a gate carrying a book that is not the next one in the sequence. Plausible distractors come from near the answer, not from anywhere in the canon.

**Life** — a player's remaining tolerance for a wrong gate within a run.

**Bounce** — hitting a wrong gate. The run does not advance: the same row of gates returns, the speed earned so far is lost, and one life is spent. A book cannot be passed over; the order is preserved by construction.

**Speed** — how fast gates arrive, climbing as the run goes and never resetting except by a bounce. It rises toward a ceiling rather than forever.

**Start boost** — an elevated starting speed, earned by a clean route rather than granted by a menu.

**Mode** — a ruleset played over the shared content, with its own way of scoring and ending. Book Order is the first mode; the game is a container for modes.

**Locale** — the language and script a player plays in. Book names and interface text are always in the same locale.

**Alias** — a widely used alternate name for a book, shown when a player meets the book, so a player who knows it by another name recognises it.
